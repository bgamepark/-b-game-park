# B級ゲームパーク 18本版（トップページ強化版）

このZIPには、18本のミニゲームと、見た目を強化したトップページが入っています。

## 主な変更点
- トップページに大きなヒーローエリアを追加
- おすすめゲームのカード表示を追加
- すべてのゲーム一覧を見やすく整理
- 各ゲームページの見た目を少し豪華に調整
- 画像素材（hero-banner / 一部サムネイル）を同梱

## 反映方法
1. ZIPを解凍する
2. 中に入っている `index.html` `assets` `games` `README.md` `MEMO.md` をまとめてGitHubリポジトリにアップロードする
3. 公開URLをリロードして確認する
