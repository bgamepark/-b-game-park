# B級ゲームパーク 18本入りテスト版

GitHub Pages 用の静的サイト一式です。

## ファイル構成

- `index.html`：トップページ
- `assets/styles.css`：共通デザイン
- `assets/games-data.js`：ゲーム一覧データ
- `assets/app.js`：共通ゲームエンジン
- `games/*.html`：各ゲームページ
- `MEMO.md`：開発メモ

## 反映方法

1. このZIPを解凍する
2. GitHubリポジトリのトップで `Upload files` を選ぶ
3. 解凍した中身をまとめてアップロードする
4. Commit changes を押す
5. GitHub Pages の公開URLを再読み込みする

※ ZIPファイルそのものをアップロードしてもサイトは更新されません。必ず解凍した中身をアップロードしてください。
